- 唯一定义处：`src/config/profileConfig.ts:9` `avatar: "assets/images/avatar.jpg"`（当前文件 `src/assets/images/avatar.jpg`，1024×1024 默认蓝色小鸟，93kB）。支持三种写法：src 相对路径（推荐，会被优化）、`/` 开头走 public 不优化、远程 URL 不优化。
- 渲染处 1｜侧边栏 & 移动端底部 Profile（`src/components/widget/Profile.astro:31-39`）：`ImageWrapper` 外层 div 只有 `profile-avatar-image` 这个**纯选择器钩子类**（全库无对应 CSS 规则），父级 `<a>` 只有 `max-w-48 lg:max-w-none`，**没有 aspect-ratio/固定高度** → 图片按原始宽高比显示，**非方形也不会被裁切**（高度随图变化）。外层宽度：移动端 ≤12rem(192px)、桌面端 = 侧边栏全宽。`widths={[350]}` → 建议源图 ≥700px 以支持 2x。
- 渲染处 2｜动态页头像（`src/components/pages/dynamic/DynamicItem.astro` / `DynamicItemTemplate.astro` + `src/styles/dynamic.css:192-205`）：`.dynamic-avatar` 固定 `3rem×3rem`、`border-radius:50%`，img `object-fit:cover` → **强制圆形并居中裁切**，非方形图会被切掉边缘。
- 渲染处 3｜分享海报（`src/pages/posts/[...slug].astro:82-85`）直接复用页面上 `.profile-avatar-image img` 的 URL，无独立规格。
- 结论：技术上不强制方形，但推荐 1:1 方图（否则动态页圆形头像会裁切、侧边栏高度会不一致）。

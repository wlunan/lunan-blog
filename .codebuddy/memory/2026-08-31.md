## 修复 pnpm dev 报错（ERR_INVALID_ARG_VALUE 空字节 + safe-delete 超时）

**症状**：`pnpm dev` 报 `TypeError: options.env['npm_config_manage_package_manager_versions'] must be a string without null bytes`。

**根因 1：`.npmrc` 混合编码损坏**
- 原 `.npmrc` = ASCII 的 `manage-package-manager-versions = true` + 用 PowerShell 追加的 UTF-16LE 版 `node-linker=hoisted`（每字符带 `\0`）。
- npm/pnpm 解析后配置值变成 `true` + `n\x00o\x00d\x00e...`，spawn 子进程时因空字节抛错。
- 修复：用 UTF-8 无 BOM 重写 `.npmrc`（内容 `manage-package-manager-versions = true` + `node-linker=hoisted`）。
- 注意：write_to_file 工具对该"二进制"文件写入无效，需用 `[System.IO.File]::WriteAllText(path, content, (New-Object System.Text.UTF8Encoding($false)))`。

**根因 2：CodeBuddy 注入的 safe-delete 钩子导致 `pnpm install` 失败**
- CodeBuddy 通过 `NODE_OPTIONS=--require=...\genie\out\vendor\shim\node-language-shim.cjs` 预加载。
- shim 在 `CODESBUDDY_SESSION_ID`/`CLAUDE_SESSION_ID` 存在时加载 `node-safe-delete-shim.cjs`；`CODESBUDDY_SAFE_DELETE_ENABLED !== '0'` 时启用。
- 该钩子把删除操作转给 `GENIE_TRASH_DIR\win32-x64.exe`（genie-trash），spawnSync 超时 → `ERR_PNPM_LINKING_FAILED [safe-delete]`。
- 修复：执行 pnpm 前设 `$env:CODEBUDDY_SAFE_DELETE_ENABLED='0'`（删除走原生 fs，install 8.8s 完成）。

**验证**：`pnpm astro --version` 正常，`pnpm dev` 可启动。
